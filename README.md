Resumo sobre o desafio

Criando Máquinas Virtuais na Azure  
As Máquinas Virtuais (VMs) na Azure permitem executar sistemas operacionais e aplicações em um ambiente virtualizado na nuvem.  

 Passos para Criação:
1. Acesse o Azure Portal → "Máquinas Virtuais" → "Criar VM".  
2. Defina Configurações Básicas:  
   - **Sistema Operacional:** Windows Server, Linux (Ubuntu, CentOS, etc.).  
   - **Tamanho da VM:** Escolha entre opções como B1s (básico) ou D4s_v3 (alta performance).  
4. Configure Rede e Armazenamento:  
   -  Atribua um IP público, configure NSG (Network Security Group) para segurança.  
   - Selecione discos (SSD Premium ou HDD padrão).  
6. Revise e Implante → A VM estará pronta para acesso via SSH/RDP.  

 Casos de Uso:
- Hospedagem de aplicações web.  
- Ambientes de desenvolvimento e teste.  
- Processamento de dados em larga escala.
